# キラー数独ケージ合計制約パズルゲーム

通常の数独ルールに加えて、点線で囲まれたケージ内の数字の合計がヒント数値と一致するという制約を持つキラー数独です。5問のパズル（易しい2問・普通1問・難しい2問）をハードコードで収録し、難易度別フィルターで選択できます。入力数字のリアルタイム検証（解答との照合・エラーカウント）・メモ機能（小数字の候補入力）・ヒント機能（1セルずつ正解を教える）・解答表示機能を搭載し、タイマーでクリアタイムを計測します。

## 使い方

難易度と問題番号を選択してパズルを開始します。セルをクリックして選択後、画面下の数字パッドまたはキーボードの数字キーで入力できます。メモモードをオンにすると小さな候補数字が入力できます。矢印キーでセル間を移動できます。
